# Command line

Generated by `tests/reference_docs.py` from the flag and command registries (`src/cli/`, `src/app/`); edit that, not this page.

## Flags

| Flag | Sets | What |
| --- | --- | --- |
| `--show-system-prompt` |  | show the resolved system prompt without a model call; --json includes sources |
| `--control JSON\|-` |  | run a native memory, skills, schedule or prompt operation without a model |
| `--web` |  | start or reuse this user's web host |
| `--web-port PORT` | `UAGENT_WEB_PORT` | loopback web listener port (default 8080) |
| `--web-origin ORIGIN` | `UAGENT_WEB_ORIGIN` | exact browser origin behind a local HTTPS or tailnet proxy |
| `-p PROMPT` |  | run one turn, print only the final answer, exit |
| `--yolo` |  | act without asking; the sandbox setting still applies, and what always needs a person still does |
| `--json` |  | emit a stable JSON envelope in headless mode |
| `--json-stream` |  | emit versioned JSONL events in headless mode |
| `--budget USD` |  | cap this conversation's total spend between model calls |
| `--token-budget TOKENS` |  | cap this conversation's generated tokens between model calls |
| `--plain` | `UAGENT_PLAIN` | screen-reader output: labelled lines, no animation |
| `--no-memory` | `UAGENT_MEMORY` | disable memory recall and writes for this conversation |
| `--detail LEVEL` | `UAGENT_DETAIL` | detail shown in this terminal: minimal, default or full |
| `--model SELECTION` | `UAGENT_MODEL` | conversation model as [provider/]model[:effort] |
| `--image-model SELECTION` | `UAGENT_IMAGE_MODEL` | read attached images with this model route |
| `--web-search-model SELECTION` | `UAGENT_WEB_SEARCH_MODEL` | model route for web search |
| `--memory-model SELECTION` | `UAGENT_MEMORY_MODEL` | model route for background memory extraction |
| `--debug[=PATH]` |  | write a sensitive reconstructable JSONL trace |
| `--attach PATH` |  | send an image or document with the first message |
| `-c` |  | continue the most recent conversation |
| `--resume` |  | pick a saved conversation to continue |
| `--version` |  | print the installed version |
| `--trust-project-config` |  | trust this folder's .mcp.json |
| `--help` |  | show this help |

## Slash commands

Typed into a conversation. A command the web has a control for is offered there as that control.

| Command | In | What |
| --- | --- | --- |
| `/agents` | terminal | list this conversation's agents and theirs |
| `/attach PATH\|clear` | terminal | attach a file to the next turn |
| `/compact` | terminal, web | summarize conversation to prevent hitting the context limit |
| `/context` | terminal, web | show current model request |
| `/config [KEY\|user\|project\|conversation KEY=VALUE\|unset KEY\|reset]` | terminal, web | show changed settings, one setting by scope, change one, or reset a scope |
| `/fork [TITLE] [@TURN]` | terminal, web | branch this conversation, optionally at user turn N |
| `/rewind [N]` | terminal, web | fork before your message N to edit it; bare, list the numbers |
| `/share` | terminal, web | export transcript as markdown |
| `/permissions [default\|ask\|auto\|yolo\|rules\|forget N\|forget all]` | terminal, web | show or change the approval mode, or this repository's remembered actions |
| `/rename TITLE` | terminal, web | rename this conversation |
| `/instructions [edit user\|project]` | terminal, web | show or edit instructions |
| `/http [INDEX [request\|response]]` | terminal, web | inspect captured HTTP attempts (latest by default) |
| `/diff` | terminal, web | show git diff (including untracked files) |
| `/cost` | terminal | show tokens and spend by route |
| `/changes` | terminal | list the files the last turn changed |
| `/undo [FILE]` | terminal | put back the files the last turn changed, or one of them |
| `/effort LEVEL` | terminal | choose how much reasoning effort to use |
| `/help` | terminal | show this help |
| `/init` | terminal, web | create an AGENTS.md file with instructions for µAgent |
| `/memory [list\|get KEY\|set KEY @FILE\|forget KEY\|rename KEY TARGET\|copy KEY TARGET\|import [NAME\|all]]` | terminal, web | manage this folder's and global memories |
| `/skills [list\|get ID\|set KEY @FILE\|forget ID\|enable ID\|disable ID\|import [NAME\|all]]` | terminal, web | inspect and manage installed skills |
| `/schedule [list\|run ID\|pause ID\|resume ID\|forget ID\|stop RUN\|JSON]` | terminal, web | manage scheduled tasks and runs |
| `/model NAME\|QUERY\|all [--default]` | terminal | choose the model for this conversation, or for all new ones; a query searches every provider |
| `/ps [ID [output\|stop]]` | terminal | inspect or stop activities |
| `/quit` | terminal | leave; the conversation keeps running and can be resumed |
| `/reset` | terminal, web | start a new conversation |
| `/clear` | terminal | clear the screen |
| `/review [TARGET]` | terminal, web | review my current changes and find issues |
| `/sessions [PREFIX]` | terminal | resume a saved conversation, optionally matching PREFIX |
| `/status` | terminal, web | show this conversation's configuration and token usage |
| `/tools [on\|off NAME\|profile NAME\|reset]` | terminal, web | inspect or choose tools for this conversation |
| `/mcp [retry\|on\|off NAME]` | terminal, web | show MCP servers; retry one or switch it on or off |
| `/restart` | terminal | restart this conversation to apply settings that need it |
| `/btw QUESTION` | terminal, web | ask a side question without adding it to the conversation |
| `/detail [minimal\|default\|full]` | terminal, web | set how much of the agent's work is shown, everywhere |
| `/yolo` | terminal | toggle acting without asking; the sandbox setting still applies |
| `/plan` | terminal | toggle plan mode: research and write a plan; nothing changes until you approve it |
| `/overview` | terminal | this folder at a glance: what works, what needs you, spend and changes |
| `/open ID` | terminal | switch to a conversation of this folder |
