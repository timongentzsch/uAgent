# Settings

Generated by `tests/reference_docs.py` from the settings registry (`include/core/config_registry.h`); edit that, not this page.

A setting is saved under its key for all conversations or for one folder (`/config`, the web's Settings), or set for a process by its variable. Later wins: all conversations, this folder, environment, command line, this conversation. A change applies from the next message, or after a restart (`/restart`) where the last column says so.
