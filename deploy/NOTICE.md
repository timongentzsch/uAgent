`seccomp-chrome.json` is [Docker's default seccomp profile](https://github.com/moby/profiles/blob/main/seccomp/default.json) with `clone`, `setns`, and `unshare` allowed so Chrome can create its own user namespace, as the [Playwright Docker seccomp profile](https://github.com/microsoft/playwright/blob/main/utils/docker/seccomp_profile.json) does. Take it again from the current default when Docker's changes: a copy that falls behind refuses system calls current container runtimes need (runc 1.5 crashes starting a container without `openat2`), and µAgent's own command sandbox needs the Landlock calls.
